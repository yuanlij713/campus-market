# 设计文档

## 1. 总体架构

```
浏览器（Vue3 SPA + Element Plus）
        │  RESTful JSON / Authorization Token
        ▼
Spring Boot（内嵌 Tomcat，8080 端口）
  ├─ AuthInterceptor   登录校验 / 管理员鉴权
  ├─ Controller 层     用户、商品、订单、消息、评价、举报、管理端
  ├─ MyBatis Mapper    SQL 注解映射
  └─ 数据源            H2（MySQL 兼容模式，默认）/ MySQL 8.0（可选）
```

- 前端为无构建 SPA：Vue3 全局构建 + Element Plus 全局组件，hash 路由，全部静态资源本地化，满足首屏 ≤2s。
- 后端统一返回 `{code,msg,data}`，统一异常处理（GlobalExceptionHandler）。
- 鉴权：UUID 令牌（内存存储，7 天有效），`Authorization` 请求头；管理端路径由拦截器统一校验 `role=1`。

## 3. 数据库设计（9 张表）

- **user** 用户：username/password(sha256+salt)/student_id/email/campus/role/status/verified
- **category** 分类：name/parent_id/sort
- **product** 商品：user_id/title/description/price/original_price/category_id/campus/images/stock/status/views
- **favorite** 收藏：user_id+product_id 唯一
- **orders** 订单：order_no/product_id/buyer_id/seller_id/price/quantity/status/meet_location/remark
- **message** 私信：sender_id/receiver_id/product_id/content/read_flag
- **review** 评价：order_id+reviewer_id 唯一，rating 1-5
- **report** 举报：reporter_id/product_id/reason/status/handle_result
- **announcement** 公告：title/content

商品状态机：0 待审核 →（管理员通过）→ 1 在售 →（售罄/下架）3 已下架；审核拒绝为 2；编辑后回到 0。
订单状态机：0 待确认 →（卖家接单，扣库存）1 待交付 →（买家确认）2 已完成；0/1 可取消为 3。

## 4. 关键流程

### 发布商品
用户提交图文 → 状态置 0 待审核 → 管理端审核通过 → 上架展示（1）；拒绝（2）或下架（3）后前台不可见。

### 交易闭环
买家浏览/搜索 → 详情页私信沟通 → 下单（0）→ 卖家确认接单（1，原子扣库存，库存为 0 自动下架）→ 线下见面交付 → 买家确认收货（2）→ 双方互评 → 信用评分沉淀到卖家主页。

### 举报处理
用户对商品发起举报 → 管理端处理：填写处理结果，可勾选联动下架商品。

### 安全设计
- 密码 SHA-256 加盐存储；接口越权校验（仅能操作本人资源）；管理员接口二次校验角色
- 上架商品强制审核；注册/核验绑定学号+校园邮箱
- 图片上传白名单校验扩展名，限制 10MB
- SQL 全部参数化（MyBatis #{}），无注入风险
