# 操作手册

## 启动系统

1. 安装 JDK 17+ 与 Maven 3.6+（或使用项目内 `settings-aliyun.xml` 加速依赖下载）
2. 构建：`mvn -s settings-aliyun.xml -DskipTests package`
3. 运行：`java -jar target/campus-market-1.0.0.jar`，或双击 `run.bat`
4. 浏览器访问 http://localhost:8080

## 用户端操作

### 注册与登录
- 打开首页 → 右上角"注册"：填写用户名、密码、昵称，建议同时填写**学号+校园邮箱**完成身份核验
- 忘记密码：登录页"忘记密码"，凭学号+校园邮箱重置

### 购买商品
1. 首页浏览推荐，或进入"商品列表"按分类/校区/关键词检索
2. 点击商品卡片进入详情：可收藏、举报、"联系卖家"在线沟通
3. 点击"立即购买"：填写数量、线下交易地点、备注 → 提交订单
4. 在"我的订单-我买到的"跟踪状态；卖家接单后线下见面，验货无误点"确认收货"
5. 订单完成后可对卖家进行 1-5 星评价

### 出售商品
1. 顶部"发布商品"：填写标题、分类、价格、库存、校区，上传图片，提交审核
2. 管理端审核通过后商品上架（个人中心-我的发布可查看状态）
3. 收到买家订单后，在"我的订单-我卖出的"点击"确认接单"
4. 支持商品编辑、下架、重新上架

### 消息
- 铃铛图标查看未读数；聊天页左侧为会话列表，右侧为对话窗口，消息每 3 秒自动刷新

## 管理端操作（admin / admin123）

登录管理员账号后，通过用户菜单进入"管理后台"：

| 菜单 | 功能 |
|---|---|
| 数据看板 | 用户量/商品量/订单量/交易额统计，订单趋势、分类与校区分布图表 |
| 商品审核 | 按状态筛选，执行通过/拒绝/强制下架 |
| 用户管理 | 搜索用户，封禁/解封违规账号 |
| 举报处理 | 查看举报，填写处理结果，可联动下架商品 |
| 公告管理 | 发布/编辑/删除平台公告（展示于首页轮播） |
| 分类管理 | 新增/编辑/删除商品分类 |

## 常见问题

- **端口占用**：修改启动参数 `--server.port=8081`
- **数据重置**：停止应用后删除项目目录下 `data/` 文件夹，重启后自动重建并写入种子数据
- **切换 MySQL**：执行 `sql/mysql-schema.sql` 建库，修改 `application-mysql.yml` 连接信息，以 `--spring.profiles.active=mysql` 启动
