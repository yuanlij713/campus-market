# 接口文档

统一约定：
- 基础路径 `/api`，请求/响应均为 JSON（`Content-Type: application/json`）
- 响应结构：`{ "code": 0, "msg": "ok", "data": ... }`；`code=0` 成功，其余失败；HTTP 401 表示未登录/登录过期，403 表示无管理员权限
- 登录接口返回 `token`，之后请求头携带 `Authorization: <token>`

## 认证 AuthController

| 方法 | 路径 | 鉴权 | 说明 | 请求体 |
|---|---|---|---|---|
| POST | /api/auth/register | 公开 | 注册（填学号+校园邮箱自动核验） | {username,password,nickname,studentId,email,campus} |
| POST | /api/auth/login | 公开 | 登录，返回 {token,user} | {username,password} |
| POST | /api/auth/forgot | 公开 | 学号+邮箱校验后重置密码 | {studentId,email,newPassword} |
| POST | /api/auth/logout | 登录 | 退出登录 | - |
| GET | /api/auth/me | 登录 | 当前用户信息 | - |
| POST | /api/auth/verify | 登录 | 学生身份核验 | {studentId,email} |

## 商品 ProductController / MiscController

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| GET | /api/products | 公开 | 分页查询：?categoryId=&campus=&keyword=&page=&size= → {list,total} |
| GET | /api/products/{id} | 公开 | 详情（自动累计浏览量） |
| GET | /api/products/mine | 登录 | 我的发布（全部状态） |
| POST | /api/products | 登录 | 发布商品 {title,description,price,originalPrice,categoryId,campus,images,stock}，进入待审核 |
| PUT | /api/products/{id} | 登录 | 编辑商品（重新进入待审核） |
| PUT | /api/products/{id}/offshelf | 登录 | 下架 |
| PUT | /api/products/{id}/onshelf | 登录 | 重新上架（重新审核） |
| GET | /api/categories | 公开 | 分类列表 |
| GET | /api/announcements | 公开 | 最新公告（5条） |
| POST | /api/upload | 登录 | 图片上传，multipart 字段 `file`，返回图片 URL |

商品 status：0 待审核 / 1 在售 / 2 审核拒绝 / 3 已下架

## 订单 OrderController

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| POST | /api/orders | 登录 | 下单 {productId,quantity,meetLocation,remark} |
| GET | /api/orders?role=buyer\|seller | 登录 | 我的订单（含 reviewed 是否已评价） |
